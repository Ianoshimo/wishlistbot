# План: организовать официальную партнёрку маркетплейсов

Строится поверх ресёрча `Контекст/ресёрч-партнёрки-маркетплейсов-2026-09-29.md`
(разбор программ по состоянию на сентябрь 2026) - здесь конкретные шаги
"куда идти и что подавать", а не повторный разбор условий. Цель - получить
официальный API-токен на каждую площадку, чтобы перестать зависеть от
платного обхода антибота через Apify (`backend/src/services/wildberriesApify.ts`,
см. `Продукт/беклог-баги-итерация-1.md`, "найти бесплатное решение").

Важная оговорка из ресёрча: все четыре программы описаны в терминах
"блогер/канал", а не "бот/мини-апп". Прежде чем подавать заявку по каждой
площадке, стоит напрямую написать в поддержку программы с вопросом,
пройдёт ли модерацию бот-вишлист без публичного контент-канала -
черновики таких писем уже есть в
`Контекст/черновики-обращений-в-поддержку.md`, готовы к отправке.

## Порядок по приоритету (проще всего → сложнее)

### 1. Яндекс.Маркет - начать отсюда

Модерация быстрее всех (1 рабочий день), принимает физлиц без юрлица.

**Как подать:**
1. Зайти на [affiliate.market.yandex.ru](https://affiliate.market.yandex.ru/)
2. Раздел для блогеров - [affiliate.market.yandex.ru/influencers](https://affiliate.market.yandex.ru/influencers)
3. Регистрация через Яндекс ID (тот же аккаунт, что и остальные сервисы
   Яндекса)
4. В анкете указать способ размещения - скорее всего придётся выбрать
   ближайшую по смыслу категорию (например "сайт"/"приложение", если нет
   пункта под Telegram-бот конкретно) и в свободном поле описать формат:
   "Telegram Mini App - вишлист с бронированием подарков, ссылка на товар
   выдаётся получателю при добавлении позиции"
5. После одобрения в личном кабинете появится API/фид для генерации
   партнёрских ссылок - там же будет точное окно атрибуции (в открытых
   источниках расходится 7-30 дней, см. ресёрч)

**Что должно быть готово до подачи:** ИНН (для физлица/самозанятого) и
реквизиты для выплат - без этого не даёт завершить регистрацию.

### 2. Ozon Blogger - подавать после Яндекса

**Как подать:**
1. [ozon.ru/bloggers](https://www.ozon.ru/bloggers)
2. Заявка требует статус самозанятого (оформляется за один день в
   приложении "Мой налог", если ещё нет)
3. Анкета исторически спрашивает "ссылку на Telegram-канал" - это узкое
   место. Вариант обхода: указать ссылку на самого бота
   (`https://t.me/wishhdesk_bot`) в поле канала и в комментарии пояснить
   формат - но заранее нет гарантии, что модерация пропустит без
   классического канала с постами
4. Если откажут по формальному признаку "не канал" - это как раз тот
   случай, где до подачи стоит сначала написать в поддержку (черновик
   есть) с прямым вопросом, годится ли бот-формат

### 3. AliExpress (через ePN) - выше потолок комиссии, больше бюрократии

**Как подать:**
1. [epn.bz/ru/offers/ali](https://epn.bz/ru/offers/ali) - регистрация в
   партнёрской сети ePN (не напрямую у AliExpress)
2. Нужен подтверждённый статус самозанятый/ИП/ООО, резидент РФ, 18+
   (строже, чем у Яндекса и Ozon - там физлицо без статуса тоже может
   стартовать)
3. Правила ePN говорят про "личные блоги/каналы в Telegram" - перед
   подачей стоит написать в поддержку ePN (черновик готов) с вопросом про
   мини-апп именно здесь в первую очередь, так как формулировка жёстче,
   чем у Ozon
4. После одобрения - партнёрские ссылки генерируются в личном кабинете
   ePN, не на самом AliExpress

**Алгоритм регистрации и получения API-доступа (проверено живьём на
epn.bz 2026-10-01, не из памяти):**

1. **Создать аккаунт вебмастера** -
   [epn.bz/app-auth/ru/signup/user](https://epn.bz/app-auth/ru/signup/user).
   На этом шаге нужен только email/пароль + согласие на обработку
   персональных данных (чекбокс на рассылку - опционален). ИНН и
   реквизиты для выплат на создание аккаунта НЕ требуются - их просят
   позже, при первом запросе на вывод средств.
2. **Привязать AliExpress как оффер** - в кабинете найти
   [раздел AliExpress](https://epn.bz/ru/offers/ali) и нажать "Начать
   работу" (виден только после входа).
3. **Телеграм-бот ePN Affiliate
   ([epn.bz/ru/telegram-bot](https://epn.bz/ru/telegram-bot)) -
   опциональный инструмент, не обязательный шаг.** Это отдельный
   встроенный бот самой ePN для ручной генерации партнёрских ссылок прямо
   из Telegram (написал товарную ссылку боту - получил партнёрскую в
   ответ). К получению API-доступа и к боту проекта `@wishhdesk_bot`
   отношения не имеет - можно пропустить, если ссылки будут генерироваться
   программно через API (п.5).
4. **Включить API** - документация:
   [epn.bz/api/ru](https://epn.bz/api/ru/) (EPN API v2, Early Beta,
   есть OpenAPI-спека для экспорта в Postman/codegen).
5. **Получить токен доступа** - `POST https://oauth2.epn.bz/token` с
   телом `{"grant_type":"password","username":"<email>","password":"<пароль>","client_id":"web-client"}`
   -> `access_token` + `refresh_token`. Отдельно регистрировать
   "приложение"/`client_secret` не нужно: `client_id=web-client` - это
   публичный идентификатор клиента, а не секрет, grant `password` рассчитан
   именно на случай "я сам хожу в свой же аккаунт с сервера", что и есть
   наш кейс (OAuth-редирект с `client_secret` нужен только для сценария
   "стороннее приложение действует от имени ДРУГОГО пользователя ePN", не
   нашего).
6. **Генерировать партнёрские ссылки программно** - `POST
   /creative/create` (передать товарную ссылку AliExpress, получить
   партнёрскую в ответ) или `GET /creatives/deeplinks` (список уже
   созданных). Токен передаётся как обычно для OAuth2 - заголовком
   `Authorization: Bearer <access_token>`.
7. **Куда это подключать в коде** - по аналогии с
   `backend/src/services/wildberriesApify.ts`: отдельный модуль
   `services/aliexpressEpn.ts` с тем же наружным интерфейсом
   `{title, imageUrl, price?}` + вызов `/creative/create` для получения
   партнёрской ссылки на сохранение вместе с позицией (см. "Что сделать
   параллельно" ниже про общий интерфейс).

Ставки на AliExpress (из `epn.bz/ru/offers/ali`, SLA по выплате - до 70
дней, cookie 15 дней СНГ / 3 дня не-СНГ): hot sale товары до 70-71%,
обычные аффилиатные товары 0.8-7.8% в зависимости от продавца,
неаффилиатные товары - 0% (или 0.25% только для участников
мотивационной программы). Большая часть обычных позиций вишлиста
(не hot sale) скорее всего попадёт в диапазон 1-8%, а не в заголовочные
"до 70%" - это цифра для акционных товаров.

**Открытые вопросы по ePN/AliExpress (не проверено, требует уточнения):**

- **Пройдёт ли мини-апп модерацию оффера AliExpress.** Правила ePN
  сформулированы в терминах "личные блоги/каналы в Telegram" - Вишлист-бот
  не блог и не канал с постами, а утилитарный Mini App. Черновик письма в
  поддержку ePN уже есть в
  `Контекст/черновики-обращений-в-поддержку.md`, но не отправлен - без
  ответа риск отказа при подаче остаётся неизвестным.
- **Засчитается ли клик из Telegram WebView как переход с нужным
  регионом/устройством.** ePN привязывает полную комиссию к совпадению
  региона доставки заказа с регионом по IP и языку устройства при переходе
  по ссылке (п. "Атрибуция" на `epn.bz/ru/offers/ali`). Переход
  происходит через `target="_blank"` внутри Telegram WebView, а не из
  обычного браузера - не проверено, корректно ли WebView передаёт
  IP/locale для этой логики, или часть кликов может не засчитываться.
- **`client_id=web-client` для серверных запросов - предположение по
  документации, не проверено реальным вызовом.** В API-доке он описан как
  "id клиента, с которого осуществляется запрос (мобильное приложение,
  веб, плагин)" без явного "подходит для сервер-ту-сервер интеграций" -
  не исключено, что правильный путь - написать в поддержку ePN
  (`support@epn.bz`) и спросить, какой `client_id` использовать для
  бэкенд-сервиса, а не веб-кабинета.
- **Чей именно статус самозанятого/ИП нужен для регистрации в ePN.**
  Зафиксировано решение (`CLAUDE.md`, "Ключевые решения") - партнёрский
  доход с маркетплейсов самозанятый покрывает, но не зафиксировано, оформлен
  ли он уже у основателя лично - без этого статуса ePN не даст вывести
  деньги (хотя сам аккаунт создать можно и без него, см. шаг 1 выше).
- **Срок модерации заявки на оффер AliExpress внутри ePN** - в открытых
  источниках не нашёл (в отличие от Яндекс.Маркета, где явно "1 рабочий
  день") - узнается только по факту подачи, в личном кабинете.

### 4. Wildberries - пока пропустить

Ресёрч уже показал: универсальной партнёрки под внешние сайты/боты нет,
единственная монетизация - видео до 90 секунд внутри собственного
приложения Wibes, куда диплинк из бота не встраивается. Пока WB не
откроет что-то похожее на программы остальных трёх площадок, подавать
здесь нечего. Именно поэтому для Wildberries сейчас используется платный
обход через Apify (`Продукт/беклог-баги-итерация-1.md`).

## Что сделать параллельно с подачей заявок

- Отправить письма в поддержку (черновики в
  `Контекст/черновики-обращений-в-поддержку.md`) - **до** подачи заявки в
  Ozon и ePN конкретно, так как именно у них формулировки правил жёстче
  всего про "канал/блог".
- Не хардкодить ссылку на одну сеть в коде - прикидка уже заложена
  комментарием в `Продукт/роадмап-5-итераций.md` (итерация 3): "закладывать
  бот на смену партнёрской сети". Когда появится первый одобренный
  токен - подключать через ту же структуру, что сейчас у
  `services/wildberriesApify.ts` (отдельный модуль на площадку, общий
  интерфейс `{title, imageUrl, price?}` наружу), чтобы не переписывать
  вызовы в роутах.

## Ожидаемый результат по срокам

- Яндекс.Маркет: решение за 1 рабочий день после подачи.
- Ozon и ePN: сроки модерации в открытых источниках не указаны -
  проверить в личном кабинете после подачи, при задержке - писать в
  поддержку.
- Как только придёт первый токен - на очереди задача "подключить
  партнёрский API вместо og-парсинга для соответствующей площадки" (не
  заведена отдельно, завести когда появится реальный токен на руках).
