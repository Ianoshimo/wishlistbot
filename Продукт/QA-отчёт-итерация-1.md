# QA-отчёт: итерация 1 (ядро - вишлист и бронь), 2026-10-01

Сводный отчёт по трём заходам ручного тестирования за день. Детали по
каждому багу (шаги воспроизведения, конкретные файлы и строки) -
`Продукт/беклог-баги-итерация-1.md`, этот документ - срез статуса на
сейчас, для быстрого понимания "что проверено и в каком состоянии".

## Методология

Без автоматизированного фреймворка - вручную, тремя способами
одновременно: клики в браузере через локальный стенд
(`http://localhost:5173`), точечные проверки API напрямую через `curl`
(коды ответов, тело ошибок), прямые правки БД для труднодостижимых
краевых случаев (просрочка TTL брони, гонка из 20 параллельных запросов).
Правки в код вносились и тут же перепроверялись живьём, а не откладывались
отдельным циклом.

## Заход 1 - первый прогон по `флоу-итерация-1.md`

Нашёл **15 багов уровня Blocker/High**:

- **5 Blocker** - все исправлены и подтверждены повторным тестом в тот же
  день: бронь/покупка собственного подарка, полностью открытое удаление
  позиций без авторизации, утечка внутренних ошибок (Zod/Prisma) наружу
  клиенту как `500`, полное отсутствие обработки ошибок на фронтенде,
  гонка при одновременной брони (проверено 20 параллельными запросами -
  ровно 1 успешный).
- **10 High** - заведены в беклог, **не исправлялись** (сознательно, по
  запросу - сфокусировались на блокерах). Среди них: подмена личности
  дарителя в интерфейсе ("Забронировано вами" для чужой брони), создание
  вишлиста в БД до подтверждения Onboarding, `javascript:`-ссылки в поле
  товара, открытый CORS без авторизации, незащищённый календарный фид по
  `telegramId`.

## Заход 2 - повторный прогон с фокусом на роли

Новых независимых багов не нашёл - усилил существующую находку В-6
(подмена личности): подтвердил вживую, что **сам получатель** может
попасть на карточку своего же подарка и увидеть там ложное "Забронировано
вами" про бронь, которую реально сделал даритель. Корень тот же, что и
раньше, просто более серьёзное проявление - добавлено в беклог как
уточнение к В-6, отдельным пунктом не заводил.
