## Роли и кто их закрывает сейчас

| Роль | Кто закрывает | Комментарий |
|---|---|---|
| Продукт/аналитик | Основатель + Claude | Приоритизация и решения - за основателем, формулировка спек/флоу/роадмапа - Claude |
| Backend-разработчик | Claude | Бот-логика, API, БД - пишет и проверяет типами/сборкой Claude, ревью и приёмка - основатель |
| Frontend / мини-апп разработчик | Claude | То же самое, код уже есть и собирается чисто |
| Дизайнер (UX/UI) | Claude | Дизайн-макет (17 экранов) собран через Artifact Design, не через отдельного человека |
| Юрист/комплаенс | Никто пока - отложено | Деньги и юрвопросы (103-ФЗ/54-ФЗ) сознательно не в работе, см. решение 2026-10-01 ниже. Когда понадобится - это единственная роль, которую Claude закрыть не может (нужен настоящий юрист с ответственностью) |
| Growth/маркетинг | Основатель | Набор первой тестовой группы - ручная, человеческая задача (написать знакомым, выложить в чат) |
| Data/аналитика, Corp dev | Никто пока | Актуально к итерации 4-5, рано откладывать ресурс |

## Как это меняет скорость

Узкое место - не "кто свободен по расписанию", а внимание основателя:
ревью того, что делает Claude, и решения, которые может принять только
человек (регистрация ИП, реальные переговоры, деньги). Claude может вести
несколько направлений параллельно (research-агенты, бэкенд, фронтенд,
документы) в рамках одной сессии - см. как это уже работало при сборе
ресёrча и кода итерации 1.
