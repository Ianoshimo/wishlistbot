### HTTP
- `GET /api/me` без авторизации → **401** (ожидаемо). `GET /health` → 200.
- Фронт `/` → 200, `Cache-Control: no-store`. Фикс пустого экрана в Telegram на месте.
- SPA-fallback `/w/test` → 200, `no-store`. Ассеты `assets/*.js` → `public, max-age=31536000, immutable` (корректно).
- `/index.html` → 301 на `/index`. Это особенность `serve`, не проблема: Telegram открывает `/`.
- CORS: preflight с Origin фронта → 204, `access-control-allow-origin` = домен фронта.

**Что присылать разработчику при любом провале**
