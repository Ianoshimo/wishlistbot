## Бэкенд

**Б1. Вишлист - CRUD позиций.** Создание/редактирование/удаление позиций
вручную (ссылка, опционально название и цена), привязка к получателю через
Telegram-аккаунт, генерация ссылки на вишлист для расшаривания без отдельной
регистрации. Спека: п.1, п.4. Связано с Ф1.

**Б2. Бронирование с TTL.** Бронь позиции, TTL 5 дней с автоснятием, запрет
повторной брони уже забронированной или купленной позиции, личность
дарителя не отдаётся ни в одном ответе API, включая получателю. Спека: п.2.
Связано с Ф2.

**Б3. Отметка "куплено".** Смена статуса дарителем (доверительная, без
колбэка маркетплейса), статус виден получателю, блокировка повторной брони
купленной позиции. Спека: п.3. Связано с Ф2.

**Б6. Тексты пустых и краевых состояний.** Ответы API для пустого вишлиста
и истёкшей брони - формулировки берём из спеки и макета, не придумывать
новые на этапе разработки. Спека: п.5. Связано с Ф1.

## Фронтенд (Telegram Mini App)

**Ф1. Экран вишлиста (получатель).** Список позиций со статусами
(свободно/занято/куплено) и пустое состояние. По макету - артборды `Main`,
`Empty`. Связано с Б1, Б6.

**Ф2. Карточка позиции (даритель).** Состояния доступно → забронировано →
куплено, плюс состояние истёкшей брони, переход на маркетплейс из
состояния "забронировано". По макету - артборд `ItemDetail`. Связано с Б2,
Б3.

**Ф6. Тема Telegram Mini App.** Поддержка светлой и тёмной темы через
Telegram theme params, а не собственный переключатель - в макете тема
показана как ручной тумблер для демонстрации обоих вариантов, в реальном
мини-аппе тема должна подхватываться автоматически от Telegram.

**Ф7. Добавление позиции (получатель).** Форма - ссылка на товар,
опционально название и цена. По макету - артборд `AddItem`. Связано с Б1.

**Ф8. Экран расшаривания вишлиста.** Ссылка для копирования/отправки в
Телеграме. По макету - артборд `ShareWishlist`. Связано с Б1. (Аналогичный
экран для сбора - `SharePool` - в `задачи-итерация-2-черновик.md`.)

**Ф9. Вишлист глазами дарителя.** Отдельный от `Main` view-only экран -
даритель видит статусы позиций и может открыть карточку, но не
редактирует список. По макету - артборд `SharedWishlist`. Связано с Б1,
Б2.

**Ф12. Первый запуск.** Короткий экран-объяснение при /start без своего
вишлиста и без чужой ссылки. По макету - артборд `Onboarding`. Спека: п.6.

**Ф13. Приглашение по ссылке на вишлист.** Отдельный экран для первого
перехода по чужой ссылке, до основного списка. По макету - артборд
`InviteWishlist`. Спека: п.7. Требует от бэкенда пометку "первый ли это
переход этого дарителя по этой ссылке" - в коде сейчас реализовано на
клиенте (localStorage), учёт на бэкенде по пользователю можно добавить
позже. (Приглашение на сбор - `InvitePool` - в
`задачи-итерация-2-черновик.md`.)
