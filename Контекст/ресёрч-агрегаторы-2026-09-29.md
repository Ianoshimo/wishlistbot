# Разбор платёжных агрегаторов для группового сбора денег (сентябрь 2026)

Полный отчёт фонового агента, запущен 2026-09-29. Выводы перенесены в
`Бизнес-план/бизнес-план-черновик.md` и `Продукт/спека-итерация-1.md`,
здесь - источник и детали.

## Сводная таблица

| | Т-Kassa (Т-Банк) | ЮKassa | Robokassa |
|---|---|---|---|
| **Групповой сбор (пул от N плательщиков → 1 выплата)** | Нет готового продукта под это. Есть только потребительский "Сбор денег" в приложении Т-Банка (P2P физлицо-физлицу), он без API и не встраивается в сторонний бот. Пул считаем сами: N отдельных платежей с одним `campaign_id` в своей БД. | Аналогично - нет отдельного "группового" режима, обычный чек/пожертвование. Пул - на нашей стороне через metadata. | Аналогично. Маркетинг заточен под донаты/благотворительность (ближе всего по риторике), но механика та же - отдельные транзакции, агрегируем сами. |
| **СБП** | Да, приём по QR и через API | Да | Да |

Подключение через менеджера, срок явно не найден. | Самозанятый подключается без статуса ИП, через привязку к "Мой налог". ИП/ООО - тоже. Сроки подключения не нашёл. |

| **Готовая интеграция с Telegram** | Официального SDK под Mini App/бота нет, есть сторонние модули (например tgshop.io) поверх обычного эквайринга | Официальная инструкция "Setting up payments via Telegram Bots" (webhook `SuccessfulPayment`), поддержка как провайдер в Telegram Bot Payments API и кнопка оплаты в Mini Apps | Готовые боты `@Robomerchant_bot`, `@RobokassaShopBot` + открытый пример `robokassa/telegram-pay` на GitHub - самая зрелая готовая интеграция из трёх |

Отдельно проверены специализированные сервисы под "сбор с группы":
потребительские P2P-продукты (Т-Банк "Сбор денег", Сбербанк, МТС Банк на
базе схемы НСПК, ЮMoney) - все живут только внутри приложения своего банка,
без внешнего merchant API, для встраивания в свой бот не годятся. Prodamus
рассматривался как альтернатива - тот же класс инструмента (платёжная
ссылка + кэшбэк для инфобизнеса), возврат оформляется заявкой в личном
кабинете (1-5 дней), явного программного bulk-refund API не нашли, отдельного
продукта под цель/срок/автовозврат нет. Полноценные краудфандинг-платформы
(Planeta.ru, Boomstarter) - не платёжная инфраструктура для встраивания, а
самостоятельные площадки со своей комиссией и правилами.

## Вывод

Функционально ни один из трёх агрегаторов не имеет встроенного "группового
сбора" - во всех трёх пул собираем сами на уровне приложения, агрегатор
просто обрабатывает N независимых СБП-платежей и потом делает один payout.
По совокупности лучше подходит ЮKassa: официальная интеграция с Telegram
Bot Payments, подключение самозанятого без ИП (важно на старте проекта),
понятный API возврата и отдельный payouts-продукт. Robokassa - крепкий
второй вариант за счёт самой зрелой готовой интеграции с Telegram из трёх,
но комиссия СБП для самозанятого (3,0%) заметно выше, а возврат по API
документирован хуже. Т-Kassa даёт самую низкую комиссию по СБП, но отсекает
самозанятых (нужен минимум ИП) и не имеет готовых решений под Telegram.

Риск для всех трёх - при возврате не возвращается комиссия агрегатора, это
закладывается в экономику сбора (полный возврат дарителю обходится платформе
в размере комиссии агрегатора с этого платежа). Также не подтверждено явно,
поддерживает ли каждый агрегатор чек типа "добровольный взнос/пожертвование"
без привязки к товару под 54-ФЗ - уточнить у каждого при подключении.
